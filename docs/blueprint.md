# **App Name**: RoamFree

## Core Features:

- Homepage Destination Display: Showcase key travel destinations with appealing visuals and brief descriptions.
- Detailed Destination Pages: Provide in-depth information about various destinations, including attractions, activities, and local culture.
- AI-Powered Travel Itinerary Generator: Generate a personalized travel itinerary tool based on user preferences (dates, budget, interests, destination), powered by AI.
- Travel Package Pages: Display curated travel packages with comprehensive details like inclusions, exclusions, pricing, and itineraries.
- Direct WhatsApp Booking: Enable users to book travel packages or request custom quotes directly through WhatsApp.
- Informative Footer: Include useful links such as About Us, Terms and Conditions, Privacy Policy, Contact Information, and FAQs.

## Style Guidelines:

- Primary color: Deep turquoise (#40E0D0), evocative of tropical waters, providing a sense of tranquility and adventure.
- Background color: Light, desaturated turquoise (#E0FFFF), offering a calming and unobtrusive backdrop that allows the primary color to stand out.
- Accent color: Muted sea green (#3CB371) provides a smooth visual transition that still attracts attention when necessary.
- Font: 'Inter', a sans-serif font, provides a clean and modern feel suitable for both headings and body text.
- Use simple, outlined icons to represent different destinations, activities, and amenities. Icons should maintain a consistent style and color palette.
- Implement a grid-based layout with a focus on high-quality imagery. Prioritize clear, concise information architecture with intuitive navigation.
- Subtle animations, such as smooth transitions and parallax scrolling effects, can enhance the user experience without being distracting.
